데이터 출처 및 산출 방법

1. 고속도로 노선 데이터

국가교통정보센터(ITS) 전국표준노드링크 중 ROAD_RANK = 101(고속도로) 링크만 추출해 사용했습니다. 각 지사가 관할하는 노선의 시점·종점 IC/JC 명칭을 표준노드링크의 노드에 매칭한 뒤, 그래프 최단경로(다익스트라) 알고리즘으로 두 지점 사이의 실제 도로 선형을 그대로 추출해 지사 관할구간으로 사용했습니다.

2. 적설관측지점

기상청 API허브 stn_snow.php(적설관측지점 조회)로 받은 공식 적설관측지점 669개의 지점번호·위경도를 사용했습니다.

3. 지사별 관측소 배정 기준 — 적응형 반경

각 관측지점과 지사 관할구간(위 1번) 사이의 최단거리를 계산해 배정했습니다. 한 관측지점이 여러 지사의 관할구간과 가까우면 모든 지사에 중복으로 포함됩니다(배타적 1:1 배정 아님).

  • 기본 반경: 5km
  • 5km 이내 관측소가 5대 이하이면 → 6km로 확대
  • 6km 이내도 5대 이하이면 → 7km로 확대
  • 7km 이내도 5대 이하이면 → 8km로 확대(최대)

4. 일 신적설 데이터

기상청 API허브 kma_snow1.php로 하루 00시부터 24시까지 1시간 간격으로 관측값을 조회한 뒤, 관측소별로 그날의 최댓값을 그 날짜의 일 신적설로 사용했습니다(기상청 API가 특정 시각에만 관측치를 표출하는 경우가 있어, 시간대별 데이터를 전부 확인해 누락을 방지했습니다).

5. 지사·본부 집계 방식

지사의 특정 일자 값 = 그 지사에 배정된 관측소들의 그날 값 중 최댓값. 지사의 시즌 합계 = 기간 내 일별 값의 합. 본부의 일자별 값 = 소속 지사 일자값의 평균. 본부의 시즌 평균 = 소속 지사 시즌 합계를 전부 더한 뒤 지사 수로 나눈 값.

6. 조회 기간

매 시즌 11월 15일 ~ 익년 3월 15일. 현재 2023-24, 2024-25, 2025-26 시즌 자료를 보유하고 있습니다.

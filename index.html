데이터 출처 및 산출 방법

1. 고속도로 노선 데이터

국가교통정보센터(ITS) 전국표준노드링크 중 ROAD_RANK = 101(고속도로) 링크만 추출해 사용했습니다. 각 지사가 관할하는 노선의 시점·종점 IC/JC 명칭을 표준노드링크의 노드에 매칭한 뒤, 그래프 최단경로(다익스트라) 알고리즘으로 두 지점 사이의 실제 도로 선형을 그대로 추출해 지사 관할구간으로 사용했습니다.

2. 적설관측지점

기상청 API허브 stn_snow.php(적설관측지점 조회)로 받은 공식 적설관측지점 669개의 지점번호·위경도를 사용했습니다.

3. 지사별 관측소 배정 기준 — 적응형 반경

각 관측지점과 지사 관할구간(위 1번) 사이의 최단거리를 계산해 배정했습니다. 한 관측지점이 여러 지사의 관할구간과 가까우면 모든 지사에 중복으로 포함됩니다(배타적 1:1 배정 아님).

  • 기본 반경: 5km
  • 5km 이내 관측소가 5대 이하이면 → 6km로 확대
  • 6km 이내도 5대 이하이면 → 7km로 확대
  • 7km 이내도 5대 이하이면 → 8km로 확대(최대)

4. 일 신적설 데이터

기상청 API허브 kma_snow1.php로 하루 00시부터 24시까지 1시간 간격으로 관측값을 조회한 뒤, 관측소별로 그날의 최댓값을 그 날짜의 일 신적설로 사용했습니다(기상청 API가 특정 시각에만 관측치를 표출하는 경우가 있어, 시간대별 데이터를 전부 확인해 누락을 방지했습니다).

5. 지사·본부 집계 방식

지사의 특정 일자 값 = 그 지사에 배정된 관측소들의 그날 값 중 최댓값. 지사의 시즌 합계 = 기간 내 일별 값의 합. 본부의 일자별 값 = 소속 지사 일자값의 평균. 본부의 시즌 평균 = 소속 지사 시즌 합계를 전부 더한 뒤 지사 수로 나눈 값.

6. 조회 기간 및 보유 현황

매 시즌 11월 15일 ~ 익년 3월 15일만 조회합니다. 현재 보유 중인 시즌은 아래 표와 같습니다 (자동으로 최신 상태를 표시).

7. 새로운 기간 데이터 추가하기

자동 수집 서버는 두지 않습니다 (기상청 API가 클라우드 서버의 IP를 차단하는 문제가 있어서, 안전하고 확실한 수동 방식을 씁니다). 아래 절차로 추가합니다.

  1. apihub.kma.go.kr 접속한 상태에서 브라우저 개발자도구(F12) → Console 탭에 아래 스크립트를 붙여넣고 실행 (authKey / 시작일 / 종료일만 바꾸면 됨) → txt 파일 자동 다운로드
  2. 관리자가 관리 콘솔 → "적설 자료" 탭에서 그 txt 파일을 고르고 [검사] → [저장] — 날짜를 보고 알맞은 시즌(11.15~3.15)에 들어갑니다. 결측(-99.9)은 저장하지 않습니다
  3. 저장하면 서버(Supabase)에 남아 모든 사용자 화면에 바로 반영됩니다(파일을 내려받아 저장소에 올릴 필요 없음)
(async () => {
  const AUTH_KEY = "본인의_authKey_입력";
  const START = new Date(2024, 10, 15); // 시작일 (월은 0부터: 10=11월). 하루만 받으려면 END와 동일하게
  const END   = new Date(2025, 2, 15);  // 종료일

  let allText = "";
  let d = new Date(START);

  while (d <= END) {
    const yyyy = d.getFullYear();
    const mm = String(d.getMonth()+1).padStart(2,'0');
    const dd = String(d.getDate()).padStart(2,'0');
    const dateStr = `${yyyy}${mm}${dd}`;
    const dayMax = new Map();

    for (let h = 0; h < 24; h++) {
      const hh = String(h).padStart(2,'0');
      const tm = `${dateStr}${hh}00`;
      const url = `https://apihub.kma.go.kr/api/typ01/url/kma_snow1.php?sd=day&tm=${tm}&help=0&authKey=${AUTH_KEY}`;
      try {
        const res = await fetch(url);
        const buffer = await res.arrayBuffer();
        const text = new TextDecoder('euc-kr').decode(buffer);
        text.split('\n').forEach(line => {
          if (!line || line[0] === '#') return;
          const parts = line.split(',').map(s => s.trim());
          if (parts.length < 7) return;
          const stnId = parts[1];
          const sd = parseFloat(parts[6]);
          if (isNaN(sd)) return;
          if (!dayMax.has(stnId) || sd > dayMax.get(stnId).sd) dayMax.set(stnId, {line, sd});
        });
      } catch (e) { console.error(`${dateStr} ${hh}시 실패`, e); }
      await new Promise(r => setTimeout(r, 150));
    }

    allText += `#### DATE ${dateStr} ####\n`;
    dayMax.forEach(({line}) => { allText += line + "\n"; });
    console.log(`${dateStr} 완료 (관측소 ${dayMax.size}개)`);
    d.setDate(d.getDate() + 1);
  }

  const blob = new Blob([allText], {type: "text/plain;charset=utf-8"});
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = `snow_${START.toISOString().slice(0,10)}_${END.toISOString().slice(0,10)}.txt`;
  a.click();
  console.log("완료! 파일 다운로드됨.");
})();

# 격자 예보: 두 창과 표 구분

2026-11-05 사용자 지시에 따라 4단계 화면 구현. 서버는69, Edge v6 그대로이며 이번 작업에 서버SQL 변경은 없다.

## 사용자에게 보이는 변화

- 격자를 선택하면 기존24시간 예보와 이후3시간 예보가 각각 별도 창으로 열린다. 각각 닫기·컴퓨터에서 이동/크기 조절이 가능하다. 지도 빈 곳을 누르면 둘 다 닫힌다.
- 장비 지원 → 기관별 장비 → 상단 현황 표의 실제 스타일을 확인했다. 같은 남색 `#24405C` 머리글과 흰 글자, 회청색 항목명과 흰 내용 칸, 굵은 표 경계로 구분했다. 노란 초단기 값 표시는 유지한다.
- 컴퓨터의 기본 내용/글자 배율은1→1.3(30% 확대), 기본 표 폭은396→약515px다. 기존에 사용자가 저장한 크기/위치는 유지한다. 창이 지도보다 커지지 않게 제한하고 넘치는 내용은 창 안에서 스크롤한다.
- 창 둘을 기본 위치에서 세로로 나누며 범례 공간을 확보한다. 휴대폰에서는 폭에 맞추고 각각 스크롤한다. 24시간 창을 닫으면 이후 창의 표시 공간을 넓힌다.
- 이후 칸에는 한국 시각의 시작·끝 날짜/시각을 모두 표시한다. 예: `11/6 22시~11/7 00시`. 일부 시간만 있으면 시간 수를 표시한다. 눈/비는 합계와 기존 미량 범위, 기온은 최저, 확률은 최고다. 코드 구간은 눈/비를`-`로 표시한다.

## 구현 범위와 실패 처리

`forecast/ui.js`의 기존 지도·기관 목록·24시간 표를 유지하며 새 창을 추가했다. 선택한 좌표 하나만 `forecast_cell_tail`로 읽는다. 같은 응답의24시간 캐시를 기존 창에 사용해 두 창의 범위를 맞춘다. 이전 선택의 늦은 응답은 무시한다.

이후 조회가 실패해도 기존24시간 표는 유지한다. 오류 안내에서 다시 받을 수 있다. 전체 격자의 미래 자료를 미리 받거나 화면에서 새 수집을 시작하지 않는다. 정상 수집 예약·확정 자료·기상청API 규칙은 바꾸지 않았다.

수정 파일은forecast UI/스타일, 기존 사용법 안내와 데이터 출처, 가짜 서버와 화면 시험이다. `tools/stamp_assets.py`로 캐시 꼬리표도 갱신했다.

- 전체 자동시험 **399/399**, 684.1초, 프로그램 소스 변경 없이 완료. 기존396개에 두 창·휴대폰 배치·실패 후 재시도3개를 추가했다.
- 두 창 독립 닫기, 범위/부분 시간, 미량 범위, 기온/확률, 기존 지도 범례, 이동/크기 조절·저장, 휴대폰 폭을 확인했다. 기본 배율 변경과 창별 선택자에 맞게 기존 시험을 조정했다.
- 1400×900 컴퓨터 및375×812 휴대폰 화면을 캡처해 표 구분과 두 창 배치를 확인했다. 가짜Supabase를 사용하는 시험이며 사용자 실제 로그인 계정으로 운영 화면을 조작한 것은 아니다.

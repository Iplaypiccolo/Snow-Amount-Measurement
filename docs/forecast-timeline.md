# 예보 한 줄 표·가까운24시간 연결·정량 구간만 표시

2026-11-05 사용자 추가 요청. 기존 두 창과 표 스타일을 유지하고 시간별 표의 배치·표시 범위를 변경했다. 서버69/Edge v6 그대로, SQL 변경 없음.

## 먼저 확인한 강수 표시 원인

운영 지사 화면과 DB를 읽기만 하여 대조했다. 분석 시점 원주지사 횡성군 둔내면81,125는 가까운24시간에 미량 강수~1mm가 있고, 기존 이후 표의11/6 13시~11/8 00시 정량36시각은PCP원자료 전부0이었다. 그 이후24시각은현재정량/정성규칙에따라양으로표시하지않는구간이다. 원자료 코드값1이12시각 있어도12mm로합산할수없다. 이는해당시점·격자표본이며모든격자무강수라는주장은아니다.

기존3시간 창은 가까운24시간이 빠진이후구간만표시했다. 따라서24시간 창의~1과이후3시간 창의0/-는같은시간자료의불일치가아니었다. 사용자가이제3시간표에도가까운24시간을포함하고정량이없는먼칸을제거하도록지시했다. 이번에는추가KMA API조사나수집변경을하지않았다.

## 바뀐 화면

- 24시간 표: 기존12시간씩두표 대신 **24시각 한 표**, 창 내부 가로 스크롤.
- 3시간 표: **가까운24시간부터 정량이 있는 마지막 구간까지 한 표**, 창 내부 가로 스크롤. 날짜 선택/일자별 합계는 만들지 않는다.
- 머리글은 **윗행 날짜(묶음), 아랫행 시각**. 3시간 칸은 양끝 시각을 포함하고 자정을 넘으면 날짜도양쪽표시한다. 첫·끝의짧은칸이나중간누락은시간수를표시한다.
- 실제눈·비0은숫자만빈칸으로하고시간칸은유지한다. ~1/0~3등미량범위는보존한다. 기온0℃/확률0%/영하값은숨기지않는다.
- 정량이없는먼SNO/PCP의null·코드·혼합칸은 **시간칸자체를제외**한다. 그구간기온/확률만따로늘려보여주지않는다. 숫자0과자료없음을같게처리하지않는다.
- 두 창의 독립닫기·컴퓨터이동/크기조절·기존남색머리글구분·기본1.3배는유지한다. 휴대폰에서는가로표가페이지를밀지않고창안에서만스크롤한다.

## 계산과 수정 범위

`forecast/series.js`는순수계산함수다. RPC의`upper.series`에서24개의시간별눈/비·미량상한·기온·확률을읽어KST00·03·06시등에끝나는3시간칸으로묶는다. 기존초단기혼합값을그대로사용하므로같은시각의24시간표와다른예보원자료를고르지않는다.

그뒤기존RPC의정량`tail.bins`를연결한다. 24시간경계가같은3시간칸중간이면하나로합치며눈/비/상한합계·기온최저·확률최고를구한다. 중복시간을넣지않는다. 기온/확률만있는정성칸은넣지않는다. 서버의정량/정성판단날짜규칙은그대로사용한다.

`forecast/ui.js`와스타일에단일표·가로스크롤·두행머리글을추가하고`index.html`에계산모듈을순서대로로드한다. 사용법표현과캐시꼬리표도갱신했다. 기존지도·기관목록·서버계산·확정자료는유지한다.

# 관리 콘솔 사용 안내 (`/admin/`)

로그인, 비밀번호 변경, 계정 관리, **비밀번호 일괄 설정(엑셀표)**, 접속 로그를 한 화면에서 합니다.
- 주소(병합 후): `https://iplaypiccolo.github.io/Snow-Amount-Measurement/admin/`
- 서버는 Supabase `snow-support`(서울)입니다. 이 화면에는 비밀 키가 없고, **무엇을 할 수 있는지는 서버가 매번 검사**합니다. (화면에서 버튼을 숨기는 것은 편의 기능)
- 회사 컴퓨터에서 `supabase.co` 주소가 열려야 로그인됩니다. 안 열리면 "서버에 연결할 수 없습니다"가 나옵니다.

## 1. 로그인과 비밀번호 바꾸기
1. 아이디(예: `exchungju`)와 비밀번호를 입력합니다.
2. **임시 비밀번호로 처음 로그인하면** 새 비밀번호를 정하는 화면만 나옵니다. 바꾸기 전에는 다른 화면과 자료를 볼 수 없습니다.
3. 새 비밀번호 규칙: **12자 이상, 소문자·대문자·숫자·기호 각 1개 이상**, 아이디·지사 이름을 넣지 않기, 같은 글자 4번 이상 반복 금지, `abcd`·`1234`처럼 이어지는 글자 4개 이상 금지. 입력하는 동안 어떤 조건이 충족됐는지 보입니다.
4. 비밀번호는 언제든 **내 정보 → 비밀번호 변경**에서 바꿀 수 있습니다(현재 비밀번호 필요).
5. 로그인 상태는 탭을 닫으면 사라집니다(브라우저 세션 저장소). 로그인이 만료되면 다시 로그인하라는 안내가 나옵니다.

## 2. 비밀번호 일괄 설정 (관리자 전용) — 엑셀표처럼
**비밀번호 일괄 설정** 탭에 지사·지원장비 계정이 표로 나옵니다(관리자 계정은 나오지 않음). 칸마다 새 비밀번호를 입력하거나 **엑셀에서 복사해 붙여넣고**, 한 번에 저장합니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 엑셀 한 열(비밀번호만) 붙여넣기 | 복사한 뒤 **붙여넣을 첫 칸을 눌러** 붙여넣기(Ctrl+V). 눌러 둔 칸부터 아래로 채워집니다 |
| 엑셀 두 열(아이디 + 비밀번호) 붙여넣기 | 아무 칸이나 눌러 붙여넣기. **아이디로 찾아** 채우며 못 찾은 아이디는 알려 줍니다 |
| 규칙 확인 | 칸마다 ✓ 또는 이유가 바로 보입니다(12자 미만, 대문자 없음, 아이디 포함, 다른 계정과 같은 비밀번호 등). 하나라도 틀리면 [저장]이 꺼져 있습니다 |
| 비밀번호를 정하기 귀찮을 때 | [빈 칸을 무작위 비밀번호로 채우기] → [입력한 비밀번호 CSV로 받기]로 내려받아 전달 |
| 일부만 보고 싶을 때 | 위쪽 칸에 본부·이름·아이디를 입력해 거르기(입력한 값은 유지됨) |
| 저장 | [저장 (N개)] → 확인 창에서 [확인] |

옵션 두 가지:
- **저장 후 처음 로그인할 때 본인이 비밀번호를 바꾸게 하기**(기본 켜짐): 담당자가 받은 비밀번호로 로그인하면 새 비밀번호를 정하게 됩니다. 끄면 정한 비밀번호를 그대로 쓰게 됩니다.
- **입력한 비밀번호 가리기**(기본 켜짐): 어깨너머로 보이지 않게 합니다. 무작위로 채우면 확인할 수 있게 자동으로 보이게 바뀝니다.

저장하면:
- 서버가 **같은 규칙으로 다시 검사**하고(하나라도 틀리면 아무것도 바꾸지 않음), 통과한 계정은 비밀번호를 바꾸고 **그 계정의 기존 로그인을 모두 끊습니다.** 성공한 줄은 "저장됨 ✓"이 표시되고 **입력칸은 비워집니다.** 실패한 줄은 이유와 함께 입력이 남습니다.
- **비밀번호는 접속 로그와 응답 어디에도 남지 않습니다.** 로그에는 "누가 어느 계정의 비밀번호를 설정했는지"만 남습니다.

주의:
- **계정마다 서로 다른 비밀번호**를 쓰세요. 한 곳이 알려지면 전부 뚫리는 일을 막기 위해, 같은 비밀번호를 여러 계정에 넣으면 저장되지 않습니다.
- CSV·엑셀 파일에는 비밀번호가 그대로 들어 있습니다. **전달한 뒤 바로 삭제**하세요. 가능하면 "처음 로그인할 때 바꾸게 하기"를 켜 두세요.
- 관리자 계정은 이 표로 바꿀 수 없습니다. 본인 것은 **내 정보**에서, 다른 관리자는 **계정 관리 → 임시 비밀번호 발급**으로 합니다.
- 저장하지 않은 입력이 있는 채로 다른 탭으로 가거나 창을 닫으면 경고가 나옵니다.

## 3. 계정 관리 (관리자 전용)
- 전체 계정 표(아이디, 이름, 본부, 역할, 상태)와 검색.
- **임시 비밀번호 발급**: 새 임시 비밀번호가 **한 번만** 화면에 나오고(복사 버튼), 그 계정의 로그인은 모두 끊기며 다음 로그인 때 새 비밀번호를 정하게 됩니다.
- **비활성화/활성화**: 비활성화하면 즉시 로그아웃되고 로그인할 수 없습니다. 본인 계정과 마지막 관리자는 비활성화할 수 없습니다.

## 4. 접속·수정 로그 (관리자 전용)
최근 200건을 최신순으로 보여 주며 구분(계정생성, 비밀번호설정, 비밀번호초기화, 계정비활성화, 수정 …)으로 거를 수 있습니다. 서버가 기록하며 고치거나 지울 수 없습니다. 비밀번호는 기록되지 않습니다.

## 5. 보안 설계 (이 화면)
- 페이지의 콘텐츠 보안 정책(CSP): **이 사이트의 스크립트만 실행**하고 **`*.supabase.co`로만 연결**합니다. 화면에 넣는 모든 글자는 안전 처리(`esc`)합니다(이름에 `<script>`를 넣어도 글자로만 보임).
- 로그인 토큰은 브라우저 세션 저장소에만 있고 탭을 닫으면 사라집니다. 비밀번호는 저장하지 않습니다.
- 권한 우회 시험: 관리자가 아닌 계정이 서버의 계정 함수나 기록을 직접 불러도 거절·0건입니다(자동 시험).
- 화면의 비밀번호 규칙과 서버의 규칙이 **같은 입력에서 똑같이 동작**하는지 자동으로 비교합니다(5,000개 이상).

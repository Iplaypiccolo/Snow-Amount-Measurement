# 1시간 표48시간·모달 마우스 설명 제거 (2026-11-07)

사용자 요청: 모달의 ‘정성예보’ 단어·관련 마우스 설명을 제거하고,모든 기관별 예보 모달의 마우스 설명을 없앤다. 1시간 표는48시간까지 표시한다.

## 표시

3시간 시간 머리글의 정성예보/정성포함 표시를 제거했다. 혼합 칸은 양을 합산하지 않고 `-`로 표시한다. 강수없음/강설없음·비/눈 강도 문구는 유지한다. 3시간 셀과 일별 셀의 `title`을 제거했고 모달 안의 마우스 설명은 없다. 접근성용 aria-label은 유지한다. 지도에 마우스를 올렸을 때의 격자 정보는 모달 밖이므로 변경하지 않는다.

1시간 표는 기존24시간과 추가24개의 시간별 원값을 연결한다. 첫24시간은 초단기/단기 혼합과 미량 플래그를 그대로 보존한다. 뒤24시간은 캐시의 시각별 최신 발표·해당 발표의 격자 순서로 추출한다. 기상청이 아직 제공하지 않은 시각은 빈값이며3시간 집계를 나누어 채우지 않는다. 코드인 양은mm/cm 숫자로 표시하지 않는다.48시간은표에만해당하며,지사/지도24시간요약과자동선택기준은유지한다.

## SQL80 — 사용자 승인·운영 적용 완료

기존 `forecast_cell_tail`은 앞24시간 시계열과 그뒤3시간 집계만 반환하므로 정확한48시간 표를 만들려면 추가 시간별 원값 조회가 필요하다.

[검토 원문](sql/forecast_hourly_48_80.review.sql), SHA256 `5defce264ef44821ca43c8bbaf231cb5198197b83b114f857c9d3b19e0260eff`.

새 로그인 전용 `forecast_cell_detail(nx,ny)` 하나를 추가한다. 기존 조회를 호출해 로그인·활성 계정·현재 편입 격자·신선도 검사를 통과한 뒤,기존 응답에 `hourly_tail`24개만 덧붙인다. 첫24시간과3시간 응답은 그대로다. 원자료 직접 접근은 추가로 허용하지 않는다. 새 표/삭제/예약/기상청 호출/수집 범위 변경은 없다. 화면은기존한격자조회1회를새조회1회로대체하므로요청횟수를늘리지않는다.

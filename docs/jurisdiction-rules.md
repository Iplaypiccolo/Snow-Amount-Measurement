# 기관별 관할 고속도로 — 동작 규칙 (사람이 읽는 문서)

강설량 측정 페이지의 **"기관별 관할 고속도로"** 탭이 어떻게 동작해야 하는지 정리한 문서입니다.
(자동 테스트: `tests/test_jurisdiction_core.js`, `tests/test_jurisdiction_ui.py`)

## 1. 한눈에 보기
- 지사 관할 고속도로를 **IC/JC 사이 구간**(전국 약 690개) 단위로 나눠서, 지도에서 구간을 눌러 **다른 지사로 옮길 수 있습니다.**
- **신설 기관 추가**, **지사를 다른 본부로 이동**도 같은 탭에서 합니다.
- 바꾸면 영향받는 지사만 **관측소 배정과 일별 신적설이 새 관할로 다시 계산**됩니다. (과거 시즌 포함)
- 기존 구분은 그대로 두고 **변경 내용만 별도 파일에 쌓습니다.** 되돌리려면 그 파일을 이전 커밋으로 되돌리면 됩니다.

## 2. 파일
| 파일 | 내용 | 누가 바꾸나 |
|---|---|---|
| `data/sections.json` | 구간(IC/JC 사이)의 모양과 **기본 소속** | 도구(`tools/build_jurisdiction.py`)가 생성 |
| `data/jurisdiction_changes.json` | **저장된 변경 이력** (이동·신설·본부 이동). 처음엔 비어 있음 | 관리자(화면에서 받은 파일을 커밋) |
| `data/stations.json` | 관측소 좌표 목록 (배정 계산용) | 도구가 생성. 전체 목록을 받으면 교체 |
| `data/hierarchy.json`, `data/snow_data.json` | 기존 지사·관측소·신적설 데이터 | 기존 방식 |
| `jurisdiction/core.js`, `ui.js`, `style.css` | 계산 / 화면 / 디자인 | 개발 |

## 3. 화면 사용법
1. 탭을 열면 지도에 구간이 **본부별 색**으로 보입니다. 구간을 누르면 노선, 시점→종점 IC/JC, 길이, 소속이 팝업으로 나옵니다.
2. 왼쪽 목록에서 **지사를 누르면** 그 지사만 강조되고, 지사의 구간 목록이 펼쳐집니다.
3. **관리자 모드**를 켜면 변경할 수 있습니다.
   - 구간을 누르면 선택/해제, **Shift+클릭**은 같은 노선 줄에서 범위 선택, 목록의 체크박스로도 선택합니다.
   - 아래 바에서 **이동할 지사**를 고르고 **[이동 대기에 추가]**를 누릅니다. 지도에서 점선으로 표시됩니다.
   - **[+ 신설 기관]**: 이름과 소속 본부를 정해 만듭니다. 처음엔 관할 구간이 0개이니, 구간을 옮겨 채웁니다.
   - 지사를 눌러 열면 **본부 변경**을 고를 수 있습니다.
4. 왼쪽 아래 **변경 대기** 목록에서 개별 변경을 취소(×)하거나 **모두 취소**할 수 있습니다. (신설 기관을 취소하면 그 기관으로의 이동도 함께 정리)
5. **[미리보기]**: 바뀌는 지사의 관할 길이, 관측소 추가·제외, 최신/전체 시즌 최대 신적설의 전·후를 보여줍니다.
6. **[변경 저장(파일 받기)]**: `jurisdiction_changes.json` 이 내려받아집니다. 변경 사유를 적을 수 있습니다.
7. **[이 브라우저에 바로 적용]**: 파일을 올리기 전에 다른 탭(연도별 신적설, 관측소 지도)에서 결과를 확인하는 임시 기능입니다. 새로고침하므로 **업로드해 둔 미저장 신적설 데이터가 사라질 수 있습니다.**

## 4. 반영(저장) 방법
- 받은 `jurisdiction_changes.json` 을 저장소의 `data/jurisdiction_changes.json` 에 **덮어쓰고 커밋**합니다. 배포되면 모든 사용자에게 적용됩니다.
- **되돌리기**: 그 파일을 이전 커밋 내용으로 되돌립니다.
- ⚠ **권한**: "관리자 모드"는 화면 편의 기능입니다(암호 없음). 공개 사이트라서 화면만으로는 막을 수 없고, **실제로 반영할 수 있는 사람은 저장소에 쓸 수 있는 사람뿐**입니다. 서버(로그인)를 붙이면 관리자 아이디(2개)만 서버에서 허용하도록 바꿉니다.

## 5. 변경 파일 형식 (`events` 배열에 순서대로 쌓임)
```
{ "t":"move",      "sections":["S0001","S0002"], "to":"B012" }     구간 이동 (to = 도착 지사 번호)
{ "t":"addBranch", "id":"B060", "hq":"강원", "name":"신설지사" }    신설 기관
{ "t":"moveHq",    "branch":"B012", "hq":"충북" }                   지사의 본부 이동
```
각 이벤트에는 `at`(시각), `note`(사유), 화면 표시용 `from`·`km` 등이 함께 저장됩니다.
- 없는 지사·없는 본부·중복 이름 등 **올바르지 않은 이벤트는 무시**됩니다.
- 지사 번호(`B001`…)는 이름이 아니라 번호로 연결되어 있어, 본부를 옮겨도 연결이 끊기지 않습니다.

## 6. 적설 재계산 규칙
- **관측소 배정**(지금 사이트의 규칙 그대로): 지사 관할 선에서 **반경 5km** 이내 관측소가 **5대 초과**면 확정, **5대 이하**면 6km → 7km → 8km로 넓힙니다(8km에서 멈춤). 거리는 관할 선(점-선분)까지의 최단거리입니다. 한 관측소가 여러 지사에 중복으로 속할 수 있습니다.
- **일별 신적설**: 지사의 하루 값 = 배정된 관측소들의 **그날 최댓값**. 바뀐 지사만 전 시즌을 다시 계산하고, 나머지는 그대로입니다.
- 관할 구간이 0개인 지사는 관측소 0곳, 적설 값 없음으로 표시됩니다.
- 검증: 이 규칙으로 현재 59개 지사의 관측소와 반경을 다시 계산하면 **전부 그대로 재현**됩니다(자동 테스트).
- ⚠ **한계**: `data/stations.json` 에는 지금 **지사에 배정된 적이 있는 관측소 260곳**의 좌표만 있습니다. 새로 편입되는 지역에 다른 관측소가 있어도 빠질 수 있으니, **기상청 적설관측지점 전체 목록(좌표 포함)을 받아 교체**하면 정확해집니다. 미리보기에 이 경고가 표시됩니다.

## 7. 구간(IC/JC 사이)을 만든 방법 — `tools/build_jurisdiction.py`
- 입력: 전국표준노드링크에서 QGIS로 걸러낸 **고속도로 링크(ROAD_RANK=101)** 와 **고속도로에 닿은 노드** 파일, 노드 파일의 `.prj`.
- 기존 지사 관할 구간(`routeSegments`)을 **그대로 읽어** IC/JC 노드 위치에서 잘라 구간을 만들었습니다. (이름에 IC·JC·분기점·나들목이 들어간 노드를 IC/JC로 판별. 같은 IC의 여러 연결로 노드는 하나로 묶고 300m 미만 구간은 이웃과 합침)
- **끝점 보정**: 관할 구간의 양 끝점 중 IC/JC가 아닌 22곳을 도로를 따라 가장 가까운 IC/JC로 옮겼습니다(줄이거나 늘림, 최대 4.5km, 합계 약 23km). 늘린 부분이 다른 지사 구간과 겹치면 보정하지 않도록 되어 있습니다. 결과는 `docs/jurisdiction-build-report.md`.
- 보정으로 구간이 바뀐 **13개 지사**만 `hierarchy.json` 이 바뀌었습니다(나머지 46개 지사는 한 글자도 바뀌지 않음). 관측소 구성은 모두 그대로였고, 청송 지사의 반경 표시만 5km → 6km로 바뀌었습니다.
- **신설 노선을 가져올 때**: 같은 방식으로 새 링크·노드 파일을 걸러서 올리면, IC/JC 기준으로 나눈 구간을 `sections.json` 에 추가(소속은 비워 두고 신설 기관에 배정)하는 작업을 합니다.

## 8. 아직 정하지 않은 것
- 서버 연결 후 **관리자 아이디(2개) 검사**를 서버에서 어떻게 할지
- 신설 노선을 넣는 구체적 절차(파일 형식, 미분류 구간을 화면에서 어떻게 보여줄지)
- 지사별 반경을 **수동으로 고정**하는 기능이 필요한지 (지금은 규칙으로만 계산)

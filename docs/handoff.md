# 인계 메모 (handoff) — 채팅의 Claude 와 Claude Code 가 서로 알 수 있는 유일한 통로

**왜 필요한가**: claude.ai 채팅(회사)과 Claude Code(집, 데스크톱 앱)는 **서로의 대화를 볼 수 없습니다.** 둘이 함께 보는 것은 이 저장소뿐입니다.

## 기록 규칙 (두 쪽 모두, 2026-10-04 사용자와 합의)
1. **한 번 푸시할 때마다 "기록" 맨 위에 항목 하나**를 씁니다. 그 푸시에 들어간 내 커밋들을 **묶어서** 정리합니다(커밋마다 따로 쓰지 않음).
2. 제목에 **커밋 범위**를 적습니다: `### 날짜 · 커밋 <처음>~<마지막> · 제목`. 마지막 커밋이 이 기록을 넣은 커밋이면 `~(이 기록 커밋)`.
3. 항목 **맨 끝 줄에 작성자 서명**: `— ✍ Claude Code 작성` 또는 `— ✍ Claude 채팅 작성`. 누가 마지막으로 작업했는지는 맨 위 항목의 서명으로 압니다.
4. **상대가 쓴 항목은 고치지 않습니다.** 내 항목은 다음 푸시 때 하나로 합쳐도 됩니다(토큰을 아끼려고). 취소·되돌린 내용은 빼도 됩니다.
5. 내용은 짧게, 사실만: 바뀐 것 / 확인한 것(실제 서버·사이트 vs 시험만) / 남은 일 / 서버 변경(마이그레이션·함수) / 제안. 비밀값(토큰·키·비밀번호)은 절대 쓰지 않습니다.
6. 설계가 바뀌는 큰 결정은 `docs/decisions.md` 에도 남깁니다. "현재 상태"는 마지막에 작업한 쪽이 고쳐 둡니다.

**새 대화·세션을 시작하면**: `git pull` → `CLAUDE.md` → 이 파일(현재 상태 + 맨 위 항목들) → 필요하면 `git log -20` 순서로 읽고, 현재 상태를 한 단락으로 요약해 사용자에게 확인받습니다.

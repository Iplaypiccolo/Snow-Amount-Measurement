# 계정 목록 (아이디만 — 비밀번호는 이 저장소에 없습니다)

Supabase `snow-support` 에 만든 계정입니다. 로그인용 이메일은 아이디에서 자동으로 만든 **가짜 주소** `<아이디>@snow-support.invalid` 이고 메일은 보내지 않습니다.
- **임시 비밀번호**는 비공개 저장소(Storage `credentials` 버킷)의 CSV 파일에만 있습니다. 대시보드 → Storage → credentials 에서 내려받아 각 담당자에게 안전하게 전달한 뒤 **파일을 삭제**하세요.
- 임시 비밀번호 계정은 **비밀번호를 바꾸기 전에는 어떤 자료도 볼 수 없습니다.** 처음 로그인하면 12자 이상 새 비밀번호를 정하게 됩니다.

## 관리자 (2)

| 아이디 | 이름 | 비고 |
|---|---|---|
| `admin-01` | 관리자1 | 직접 만든 계정(비밀번호는 본인만 앎) |
| `admin-02` | 관리자2 | 임시 비밀번호 발급(`accounts-…14-21-44….csv`) |
